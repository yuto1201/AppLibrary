プライバシーポリシー

アプリ名: SubLog / 最終更新日: 2026-04-16

⚠️ 公開前にこの雛形の内容を実装と照合し、App Store Connect の「App のプライバシー」回答と必ず整合を取ってください。 特に Face ID・Spotlight・通知・解析 SDK の記述は実態に合わせて調整すること。

1. はじめに

本プライバシーポリシーは、uesugiyuuto（以下「開発者」）が提供する iOS アプリ 「SubLog」（以下「本アプリ」）における、ユーザー情報の取り扱いについて説明するものです。

2. 収集する情報

本アプリは、以下の情報をユーザーの端末内にのみ保存します。開発者のサーバーに送信することはありません。

  • サブスクリプションの情報（サービス名、金額、通貨、請求サイクル、次回請求日、カテゴリ、アイコン、カラー、メモ、URL、支払い方法、トライアル終了日など）
  • 通知設定・リマインダーの記録
  • 価格変更履歴・共有メンバー数
  • アプリの設定情報（表示言語、通貨、テーマ、アクセントカラー、Face ID ロックなど）

本アプリは、氏名・メールアドレス・電話番号・位置情報・連絡先などの個人を特定する情報を一切収集しません。

3. データの保存場所

上記データは Apple の SwiftData を用いて、端末内のアプリ専用コンテナに保存されます。 iCloud への同期は現在サポートしておらず、データは端末内に閉じています。

4. Face ID / Touch ID による認証

ユーザーの任意設定により、アプリ起動時に Face ID / Touch ID で認証を求めることができます。 生体認証は Apple の LocalAuthentication フレームワーク経由で端末内にて処理され、 生体情報が本アプリや開発者に渡ることはありません。

5. サブスクリプション自動検出

本アプリは、ユーザーが Apple ID で購入した App Store のサブスクリプションに関する情報を StoreKit 経由で取得し、登録候補として画面上に提示することがあります。 この情報は端末内でのみ処理され、開発者サーバーや第三者に送信することはありません。

6. 通知

本アプリはローカル通知のみを使用し、プッシュ通知サーバーとの通信は行いません。 通知は iOS の「設定 App」からいつでも無効化できます。

7. Spotlight 検索連携

登録されたサブスクリプションの名称を CoreSpotlight に登録し、iOS 標準の Spotlight 検索から 本アプリのデータを開けるようにします。情報は端末内インデックスにのみ保存され、Apple のプライバシーポリシーに基づき管理されます。

8. 課金情報

Premium（買い切り）の購入処理は Apple の StoreKit を通じて行われます。 開発者はクレジットカード情報等の決済情報を取得・保存しません。 購入状態（Premium 購入済みか否か）のみをアプリ内で参照します。

9. 第三者への提供

本アプリは、ユーザーのデータを第三者に提供・販売することはありません。

10. 解析・広告

本アプリは、解析ツールや広告 SDK を一切組み込んでいません。クラッシュレポートも収集しません。

11. 子どもの個人情報

本アプリは 13 歳未満の子どもを対象としておらず、意図的に子どもの個人情報を収集することはありません。

12. ユーザーによるデータ削除

本アプリをアンインストールすると、端末内のすべてのローカルデータが削除されます。

13. ポリシーの変更

本ポリシーは、必要に応じて変更されることがあります。変更があった場合は、本ページで通知します。
