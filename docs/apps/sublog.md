# SubLog

ステータス: 公開中
最終更新日: 2026-09-01

機械情報は [registry.ts](../../src/data/registry.ts) が正本。

App Store の初回公開日は 2026-04-14。2026-09-01 に [Apple Lookup API](https://itunes.apple.com/lookup?id=6761677813&country=us) を照会し、配布中の version `1.0`、`releaseDate` の `2026-04-14T07:00:00Z`、`currentVersionReleaseDate` の `2026-04-14T10:30:46Z` を確認して registry へ記録した。同じ公開説明にある「85 を超える主要サービス候補」と iOS カレンダー同期を配布版の機能根拠とする。開発中のローカル作業ツリーは配布版の正本として扱わない。

2026-09-01 に現行実装（確認時の commit `b31dbaf09637cdb72ccde5da41fe2d58ee378e1d` と未コミット作業ツリー）、既存の公開プライバシーポリシー、公開 App Store の「データの収集なし」表示を照合した。このローカル commit は配布版の証明ではなく、本文の挙動確認点を固定するための記録である。端末内保存、任意の iCloud 同期とバックアップ、FloatRates の公開為替レート取得、StoreKit の取引履歴による候補検出、ローカル通知、Spotlight、生体認証、アプリ内のお問い合わせフォームを本文へ反映し、仮文言と架空の連絡先を除去した。任意の EventKit 連携ではフルアクセスを要求し、アクセス可能なカレンダーから最初に見つかった「SubLog」を同期先に使う。同期時は既存予定を読み、登録内容と一致しない予定を削除するため、同名カレンダーへ無関係な予定を保存しない注意も本文へ明記した。データリセットで取り消すのは通常の請求日前通知であり、無料トライアル終了、契約記念日、月次レポートの保留中通知が残り得ることも実装に合わせて記録した。
