# テンプレートの使い方

## 新規プロジェクトを始めるとき

### 1. テンプレートをコピー
このフォルダごと新しいプロジェクトディレクトリにコピーする。

```bash
cp -r /path/to/template /path/to/new-project
```

### 2. プロジェクト情報を埋める
以下のファイルのプレースホルダー（括弧書きの部分）を埋める。

| ファイル | 埋める内容 |
|---------|-----------|
| `CLAUDE.md` | プロジェクト名、概要、対象ブラウザ、開始日 |
| `README.md` | プロジェクト名、概要、セットアップ手順 |

### 3. 仕様から書き始める
`docs/spec/機能仕様書.md` に何を作るかを書く。
その後 `docs/ui/画面設計書.md` で画面設計を書く。

### 4. 実装に入る
`src/` にHTML/CSS/JSを配置して実装を始める。
`docs/todo/todo.md` でタスクを管理する。

---

## ルール

- ドキュメントの先頭にはステータスと最終更新日を記載する
- 設計と実装は行き来してよい（全部書いてから実装する必要はない）
- フォルダは必要に応じて追加してよいが、既存の構成意図を崩さない
- 不要なテンプレートファイルは削除してよい
